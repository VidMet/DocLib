DocLib v2.02-rc.1

Komplett live-oppdateringspakke basert på testgrunnlaget:
- v2.02-preview.11.10: lagring/oppretting/overskriving av regel-JSON i Trimble Connect
- v2.02-preview.11.11: PSET-krav valgfritt, alle eller valgte fag
- v2.02-preview.11.11.1: headerklassene utelates fra fagavhengige objektregler

Installasjon:
1. Ta kopi av eksisterende live-filer.
2. Pakk ut innholdet direkte i live-roten for Trimble-Connect-Extension.
3. Overskriv de tilsvarende filene.
4. Behold øvrige eksisterende live-filer og mapper.
5. Kontroller DocLib v2.02-rc.1 i tittelen.

Sluttkontroll:
- Åpne/importer regel.
- Valider modell med headervalidering av og på.
- Lagre ny JSON og overskriv eksisterende JSON én gang.
- Kontroller PSET-krav for valgte fag.
