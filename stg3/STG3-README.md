# DocLib STG3 v2.03-rc.2

Produksjonsnær release candidate kopiert direkte fra fungerende STG2 v2.03-rc.1-fix.1.

Ingen funksjonsendringer er gjort i overgangen. Kun stagingmappe og versjonsidentitet er endret. STG3 skal brukes til siste produksjonskontroll.

Test før live:
1. Oppstart og prosjektlasting.
2. Utforsker, Egenskapsvalidering, Mengdesammenstilling og Kontrollplan.
3. IFC2x3, IFC4, IFC4.3 og IFC4.3_ADD2.
4. Mengdesammenstillingens fire avrundingsnivåer og kolonnevise overstyringer.
5. IFC-strukturobjekter ute av mengder og avvik.
6. Excel-, CSV- og PDF-eksport mot kjente mengder.
7. Bytt frem og tilbake mellom verktøy uten stale state eller UI-feil.
